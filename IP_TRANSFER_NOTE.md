# IP & Transfer Verification Note

Before a sale closes, the seller and buyer should verify and document ownership/transferability of:

- CryptoPool source code created for the project
- GitHub repository and repository history
- Website/deployment configuration
- Domain name, if included in the sale
- CryptoPool logo and other brand assets
- Documentation and marketing materials
- Reown project configuration (or replacement by a buyer-controlled project)
- Any third-party assets, fonts, libraries, APIs or services and their licenses/terms

This file is not a legal opinion or an IP assignment. The final purchase agreement should define exactly what is transferred and what remains with the seller.
