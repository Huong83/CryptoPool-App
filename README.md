# CryptoPool MVP v0.2

Bản giao diện nâng cấp từ prototype hiện tại.

## Đã thêm
- 8 Investment Pools mẫu
- Bộ lọc theo rủi ro
- Dashboard
- Portfolio / Transactions placeholder
- Modal xem chi tiết Pool
- Dark/Light mode
- Responsive cho điện thoại
- Trạng thái kết nối ví mô phỏng
- Cảnh báo rõ ràng: dữ liệu là demo, không cam kết lợi nhuận

## Chạy local

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
npm run preview
```

Lưu ý: phiên bản này CHƯA thực hiện giao dịch đầu tư thật, chưa nhận tiền người dùng và chưa kết nối smart contract.
