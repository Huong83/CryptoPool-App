# CryptoPool 3.1 — Professional Testnet UI

React + Vite + Reown AppKit + Wagmi dashboard for Ethereum Sepolia.

## Wallet connection
The Reown Project ID is configured as a public frontend identifier. In Reown Dashboard, make sure the deployed domain `huong83.github.io` is allowed and enable the wallet/auth methods you want to expose.

## GitHub Pages
The Vite base path is `/CryptoPool-App/` and the included GitHub Actions workflow deploys `dist/`.

## Important
This is a testnet/demo interface. It does not promise returns, collect seed phrases/private keys, or activate real-money investment. Production financial functionality requires audited smart contracts, security review, backend controls, and applicable legal/compliance review.
