# Known Limitations & Development Gaps

These are intentionally disclosed so prospective buyers can value the asset correctly.

### High priority before production
1. Production smart-contract architecture and implementation.
2. Independent smart-contract/security audit before any real funds are accepted.
3. Backend/API layer and persistent data model.
4. Real blockchain transaction/indexing infrastructure.
5. Production market-data provider and data validation.
6. Transaction state management, failure/retry handling and monitoring.
7. Authentication/account model if required beyond wallet connection.
8. Compliance/legal review for any investment, yield, custody, or financial-service functionality.

### Medium priority
- Automated tests and CI test coverage.
- Dependency lockfile and reproducible build environment.
- Error boundaries and production observability.
- Analytics and admin tooling.
- Accessibility audit.
- More extensive browser/device QA.
- Multi-chain support if part of the commercial roadmap.

### Current demo-only elements
- Static market data.
- Static demo portfolio values.
- Demo pool catalog.
- Trade simulation.
- Testnet-only presentation.
