## Public repository limitation

A browser application cannot be made completely unreadable once its client-side JavaScript is delivered to a user. Source maps are disabled for production builds, but determined users can still inspect or reconstruct client-side code. Therefore, confidentiality must be enforced primarily by repository access controls and contractual/data-room controls, not by obfuscation claims.

If the full source must remain confidential before sale, keep the authoritative repository private and publish only a controlled demo/build where commercially appropriate.

## Buyer handover rule

Do not transfer ownership merely by giving a buyer a ZIP file. The final transaction should identify the exact source revision, repositories, deployment assets, domains, brand assets, documentation, and any smart-contract rights included in the transaction, together with the permitted rights and excluded third-party components.
