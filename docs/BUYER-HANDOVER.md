# CryptoPool Pro — Buyer Handover Package

**Product:** CryptoPool Pro  
**Tagline:** Digital Asset  
**Release candidate:** 9.0.0  
**Prepared:** 2026-09-04

## Handover principle

Ownership should transfer only through a written agreement that identifies exactly what is included. A ZIP file alone is not proof of an IP transfer.

## Included asset classes

- Application source code at the agreed release commit.
- Repository history relevant to provenance.
- Build and deployment configuration.
- Buyer-facing technical and security documentation.
- UI/design assets that are owned by the seller.
- Brand/name/tagline assets only to the extent expressly assigned.
- Smart-contract source and rights only if expressly listed and actually included in the agreed release.
- Deployment configuration and domain/hosting rights only if expressly listed.

## Third-party exclusions

React, Vite, Wagmi, Viem, Reown/AppKit, external market-data services, wallet software, icons, fonts and other third-party components remain subject to their own licenses or terms. The sale must not purport to transfer rights the seller does not own.

## Final release evidence to preserve

1. Exact release commit SHA.
2. Timestamped source archive.
3. Generated `package-lock.json` after clean dependency installation.
4. Clean production build output or reproducible build evidence.
5. GitHub Pages deployment URL and deployment evidence.
6. Screenshots/video of the release candidate on desktop and mobile.
7. Testnet transaction hash(es) demonstrating the verified wallet/transaction flow, where available.
8. Dependency/license inventory.
9. External API/provider inventory.
10. Smart-contract addresses, chain IDs and source only where applicable and verified.
11. Known limitations and unresolved issues.
12. IP provenance/copyright evidence and any author/contractor assignments.

## Recommended transaction sequence

1. Buyer receives a controlled summary/demo.
2. NDA is executed before confidential source disclosure, where appropriate.
3. Buyer performs technical/IP due diligence against a fixed release SHA.
4. Commercial terms and included assets are agreed in writing.
5. Final IP assignment or license agreement is signed.
6. Payment and transfer conditions are completed according to the contract.
7. Source, documentation and agreed deployment/brand assets are handed over.
8. Both parties retain the signed agreement and release evidence.

## Status at preparation date

CryptoPool Pro is an early-stage Web3 software asset / MVP using Ethereum Sepolia testnet. It is not represented here as a production DeFi protocol or audited investment product. Revenue, users, TVL, APY, production vaults and mainnet investment functionality must not be claimed without evidence.

## Security boundary

The browser application cannot provide source-code confidentiality after delivery. Confidentiality must be achieved through repository permissions, controlled releases, NDA/data-room access and the final written transaction agreement.
