# CryptoPool — Acquisition Asset Register

## Included in this package
| Asset | Status | Notes |
|---|---|---|
| React/Vite source code | Included | Current MVP frontend source |
| UI/UX styles | Included | `src/style.css` |
| Wallet integration foundation | Included | Reown AppKit / Wagmi / Viem |
| Ethereum Sepolia configuration | Included | Testnet only |
| Product UI flows | Included | Dashboard, Markets, Pools, Trade simulation, Portfolio, Wallet |
| GitHub Pages workflow | Included | `.github/workflows/deploy.yml` |
| Website build configuration | Included | `vite.config.js`, `package.json` |
| Project documentation | Included | Buyer-facing due-diligence documents |
| Brand/icon asset | Included | `public/icon.svg` |

## Not included / not currently present
- Production smart contracts
- Audited smart contracts
- Backend services
- Production database
- Transaction indexer
- Custody infrastructure
- Real-money investment functionality
- Issued token or token allocation
- Verified revenue or user base
- Third-party security audit
- Seller's private keys, seed phrases, wallet credentials, or private infrastructure secrets

## Transfer principle
Only assets legally owned by the seller and expressly included in the final purchase/asset-transfer agreement should be represented as transferred. Third-party libraries, services, domains, accounts and credentials remain subject to their own terms and should be reassigned or replaced where appropriate.
